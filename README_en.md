## ✨ Features

- 📋 **Multi-Type Capture**: Automatically records text, rich text, images, multiple files, code snippets, and web links.
- 🌐 **Live Preview**: In-app web preview for URLs, image pan/zoom, and one-click file reveal in Finder.
- 🎨 **Visual Themes**: Automatically extracts accent colors from source app icons with native dark/light mode support.
- ⚡ **Quick Paste**: Global hotkey overlay panel with auto-paste into the active window.
- 🛠 **Automated Cleanup**: Customizable retention time & max limits with auto-deduplication and background cleanup.
- 🔒 **Privacy**: 100% local storage with no cloud syncing or network uploading.

## ⌨️ Shortcuts

| Action | Shortcut | Description |
| :--- | :--- | :--- |
| **Toggle Panel** | `⌘ + Shift + V` | Global hotkey (customizable) |
| **Preferences** | `⌘ + ,` | Open preferences |
| **Quit** | `⌘ + Q` | Quit application |
| **Quick Paste** | `Double Click` / `Enter` | Paste into active window |
| **Reveal File** | `Click Path` | Show file in Finder |

---

## 🚀 System Requirements

- **OS**: macOS 14.6 or later
- **Accessibility Permission**: Enable Tari in `System Settings` -> `Privacy & Security` -> `Accessibility`.
